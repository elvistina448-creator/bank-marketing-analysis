# bank-marketing-analysis
Power BI dashboard analyzing a bank marketing campaign using PostgreSQL, SQL, and DAX.
## Bank Marketing Campaign Performance Dashboard
### Project Overview

This project analyzes a bank's direct marketing campaign to identify the factors influencing customer subscription to term deposits. The dashboard is built using Power BI, with data stored in PostgreSQL and analyzed using SQL and DAX.

### Tools Used
- Power BI
- PostgreSQL
- SQL
- DAX
- GitHub

### Dashboard Features
#### KPI Cards
- Total Customers
- Total Subscribers
- Subscription Rate
- Average Subscriber Balance
- Average Subscriber Call Duration
#### Customer Analysis
- Subscription Rate by Job Category
- Subscription Rate by Education Level
- Subscription Rate by Marital Status
- Subscribers by Housing Loan Status
- Subscribers by Personal Loan Status
- Subscribers by Age Group
#### Campaign Analysis
- Subscription Rate by Contact Method
- Subscription Rate by Month
- Subscribers by Campaign Contacts
#### Interactive Filters
- Month
- Job Category
- Education Level
### Key Insights
-Students recorded the highest subscription rate.

-Customers without housing or personal loans were more likely to subscribe.

-Most successful subscriptions occurred after the first campaign contact.

-Cellular contact had the highest subscription rate.

### SQL Analysis

Before building the dashboard, I used PostgreSQL to clean, query, and analyze the data. The SQL analysis included:

1. Customer counts

2. Subscription rate calculations

3. Job category analysis

4. Education analysis

5. Campaign performance

6. Contact method analysis

7. Loan analysis

The insights generated from SQL were later visualized in Power BI as outlined above.
